### Learnings for future iterations
- **Reconstruct the merge record with one loop, not by trusting the tasklist description.**
  `for f in tasks/chief/completed/*.json; do jq -r '[.mergedToMain]' …; git log -1 --format=%ad
  --date=short "$sha"; done` gives stem + sha + date in one pass, and is what "verify rather than
  assume" means here. The description's counts were two records stale before the first iteration ran.
- **The `Bash` tool's cwd persists across calls.** A `cd tasks/chief/completed` in one call left the
  next call unable to find `bin/chief`. Prefix with the worktree root or use absolute paths.
- **`.chief/verify.sh` path-scopes docs work to two cheap checks** (`check-doc-links.mjs --ratchet`
  on any `*.md`, and `test/doc-sync.sh` only on `bin/|engine/|VERSION|README.md`). A ROADMAP-only
  change therefore costs seconds, not the ~10-minute full gate — run both directly while iterating.
- The doc-link checker scans **tracked files** for `docs/…md` paths. Every doc referenced in the new
  Related Docs list was confirmed present with `find docs -name '*.md'` first; `../AGENTIC-
  ENGINEERING-ADVISORY.md` is outside the repo and the checker leaves it alone.
